## Component Specifications

### 1. Docker Compose (Infrastructure)
The backend runs two core services on a shared network:
- **n8n**: Workflow engine on port `5678`.
- **Qdrant**: Vector database on port `6333`.

### 2. Python Dependencies
Managed via the global venv at `/home/white/ai/venv`. Core packages include:
- `streamlit` (v1.42.0) - Frontend
- `requests` (v2.32.3) - API communication
- `python-dotenv` (v1.0.1) - Environment variable management

### 3. n8n API Contracts

**Webhook 1: Document Ingestion**
- **Method:** POST
- **URL:** `http://localhost:5678/webhook/ingest`
- **Payload:** Multipart Form-Data with the key `data` containing the file.

**Webhook 2: Chat & Retrieval**
- **Method:** POST
- **URL:** `http://localhost:5678/webhook/chat`
- **Payload:** 
  ```json
  {
    "sessionId": "string",
    "query": "string"
  }
  ```
- **Response Schema:**
  ```json
  {
    "output": "string (the answer generated by Gemini)",
    "sources": ["list of sources used"]
  }
  ```

### 4. Chat History Storage
Chats are stored locally as JSON files in `frontend/chats/` using the format:
```json
{
  "id": "uuid",
  "title": "Short summary of first message",
  "updated_at": "ISO-TIMESTAMP",
  "messages": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

## API Keys Required
- `GEMINI_API_KEY`: Must be configured in n8n credentials for the Gemini Chat and Gemini Embedding nodes.
